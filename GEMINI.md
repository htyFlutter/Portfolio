# Core Development Rules

## 1. Plan-First Approach
- For complex implementations or refactoring, briefly state your clever plan or architectural choice before touching files. Keep it punchy and clear.
- Act decisively and modify only the relevant code blocks. Do not rewrite whole files unnecessarily.

## 2. Code Quality & Standards
- Write readable, modular, production-ready, and dry code.

- Ensure thorough error handling. Never mask failures.
